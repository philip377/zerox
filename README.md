# ZEROXGENESIS — официальный сайт (v2)

Промо-сайт игрового проекта **ZeroxGenesis**. На главной странице есть интерактивный вход в архив ZEROX, обратный отсчёт до плановой контрольной точки первой комнаты, визуал человеческого хаба, демонстрация живой стены из кубиков и отдельный раздел о сканирующем комплексе.

Все изображения встроены в `index.html`. Сайт статический: для работы не нужны база данных, сервер или дополнительные пакеты.

## GitHub Pages

Откройте **Settings → Pages → Build and deployment → Source: Deploy from a branch**, выберите **Branch: main** и **Folder: /(root)**, затем **Save**.

После успешной публикации адрес сайта: https://philip377.github.io/zerox/

> Состояние проекта: ранняя разработка. Концептуальные изображения не являются скриншотами готовой игры. Таймер показывает **плановый рубеж** первой комнаты, а не дату выхода ZeroxGenesis.
