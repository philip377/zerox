# Галерея разработки ZeroxGenesis

Новые фотографии для раздела **«Галерея»** на https://philip377.github.io/zerox/ добавляются в эту папку.

## Как добавить скриншот

1. Откройте [папку gallery в GitHub](https://github.com/philip377/zerox/tree/main/gallery).
2. Нажмите **Add file → Upload files**.
3. Перетащите фотографии (PNG, JPG, JPEG, WebP, GIF или AVIF, желательно до 20 МБ каждая).
4. Внизу нажмите **Commit changes** в ветку `main`.
5. После публикации GitHub Pages обновите сайт — новые снимки появятся в галерее автоматически.

**Для сортировки по дате** называйте файлы, например:

- `2026-10-22_potolochnyj-skaner.png`
- `2026-11-02_pomeshchenie-zeroX.webp`
- `2026-11-10_test-razborki.jpg`

Новые файлы без префикса `concept-` помечаются на сайте как **«Разработка»**. Художественные наброски и рендеры называйте с префикса `concept-` (например `concept-new-hub.jpg`), чтобы посетители не путали их с игровыми скриншотами.

Заголовок снимка автоматически берётся из его имени (дефисы и подчёркивания заменяются пробелами).

В галерее уже показываются четыре ранних концепта, встроенных в сайт. Новые изображения из этой папки появляются перед ними.

**Важно:** автоматическое получение списка файлов использует публичный GitHub Contents API. При временной недоступности API четыре встроенных концепта остаются доступны. Для сайта с большой аудиторией впоследствии стоит сделать статический каталог изображений с генерацией во время сборки.
